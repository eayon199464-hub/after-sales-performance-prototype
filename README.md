# 售后绩效管理交互原型

V1.3 评审原型，2026-11-10。人员、业务值、取数、审批及归档回执均为演示数据。

[打开在线原型](https://eayon199464-hub.github.io/after-sales-performance-prototype/)

## 演示路径

1. 总部进入「指标与规则」，从大数据指标目录获取指标；不支持手动新增。
2. 「月度方案」从已获取指标中添加方案指标、设置必选或可选及权重；适用范围为全国、大区、城市、经销商（门店）四级。
3. 下发后切换门店服务总监及演示门店，在本店方案中按员工分配指标与个人目标。权重只读。
4. 顶部进入 DMS 小程序，切换示例员工查看、确认本人方案。审批工作台按角色展示权限内各门店待办，直接从对应行审核，不用切换门店。
5. 「结果管理」汇总月度结果，展示确认、申诉、定稿状态和历史版本；查看大数据归档状态及回执。不设置人工发布或独立月度归档菜单。
6. 「申诉管理」预置多条记录，分别演示门店汇总、区域复核、总部确认及结果更新。
7. 「飞书预警」展示管理视角的消息示例。

主观评价与加扣分不可申诉；申诉结果更新后不可再次确认。经销商与门店为同一级对象。DMOC 负责业务结果台账，大数据负责数据归档；正式定稿条件和归档触发仍待确认。

## 使用说明

- 操作只保存在当前浏览器，不会影响其他访问者；右上角「重置演示」可恢复初始示例。
- 身份及门店切换仅用于演示。未接入真实大数据、组织权限或飞书发送。
- V1.3 使用独立演示记录，保留浏览器中旧版的数据。
- DMOC 建议用电脑查看，DMS 可用手机查看。下载 index.html 后也可离线演示。

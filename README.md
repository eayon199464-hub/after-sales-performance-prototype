# 售后绩效管理交互原型

V1.1 评审原型，使用虚构人员与示例数值。

[打开在线原型](https://eayon199464-hub.github.io/after-sales-performance-prototype/)

## 演示路径

1. 进入「区域作战中心 → 月度方案」，以总部管理员配置指标、权重并下发。
2. 切换门店服务总监，点击「拆解员工目标」，逐人录入目标并提交员工确认。
3. 顶部进入 DMS 小程序，分别切换示例员工，查看、确认本人的目标。
4. 回到区域作战中心，依次切换店长、区域、大区角色完成审批。
5. 「结果管理」可发布结果；员工可确认或对客观指标发起申诉，随后演示店长汇总、区域复核、总部处理。
6. 顶部「飞书预警」展示管理视角的消息示例。

总部负责指标与权重；门店服务总监负责将目标拆到员工。主观评价和加扣分不可申诉，申诉结果更新后不再次确认。

## 使用说明

- 操作保存在当前浏览器，不会同步给其他访问者。
- 右上角「重置演示」可恢复初始状态；「评审说明」可查看边界。
- 身份切换只供演示。原型未接入实际业务数据或飞书发送。
- DMOC 建议用电脑查看，DMS 可用手机查看。可直接打开仓库中的 index.html 离线演示。

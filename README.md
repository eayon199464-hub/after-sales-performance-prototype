# 售后绩效管理交互原型

V1.3 评审原型，2026-11-11 更新考核月份、方案草稿、下发与员工确认路径。人员、业务值、取数及审批均为演示数据。

[打开在线原型](https://eayon199464-hub.github.io/after-sales-performance-prototype/)

## 演示路径

1. 总部进入「指标与规则」，从大数据指标目录获取指标；不支持手动新增。
2. 「月度方案」新建方案，选择考核月份，从已获取指标中添加方案指标、设置必选或可选及权重；适用范围为全国、大区、城市、经销商（门店）四级。保存后直接回到草稿记录，可继续编辑或下发；已下发记录可查看各门店进度。考核月份表示任务归属，下发时间单独显示。
3. 下发后切换门店服务总监及演示门店，在本店方案中按员工分配指标与个人目标。保存后为「拆解草稿」，可继续拆解；提交后进入「待员工确认」。权重只读。
4. 在「查看确认进度」中查看各员工状态，通过「演示员工确认」进入对应员工的 DMS 月度方案；也可从顶部 DMS 小程序入口进入。员工只确认本人方案，管理端不能代确认。审批工作台按角色展示权限内各门店待办，直接从对应行审核，不用切换门店。
5. 「结果管理」按月份查询结果；列表保留「查看结果」和符合条件时的「录入评价」。结果详情展示申诉修改的指标、前后值、原因和处理时间。
6. 「申诉管理」预置多条记录，分别演示门店汇总、区域复核、总部确认及结果更新。
7. 「飞书预警」展示管理视角的消息示例。

「执行与预警」按考核月份查看，表格及个人明细均显示月份。DMS 方案和执行进度可切换月份，其他月份待确认任务有独立入口。各月目标、确认和审批分别保存；当月没有取数时显示暂无数据，不借用其他月份的完成值或排名。

主观评价与加扣分不可申诉；申诉结果更新后不可再次确认。经销商与门店为同一级对象。最终结果保留供历史月份查询；数据归档及批次回执由大数据侧留存和处理，业务页不设置版本与归档入口。

## 使用说明

- 操作只保存在当前浏览器，不会影响其他访问者；右上角「重置演示」可恢复初始示例。
- 身份及门店切换仅用于演示。未接入真实大数据、组织权限或飞书发送。
- 本次调整保留 V1.3 已有方案、门店分配和结果记录，无需重置。已有拆解内容会识别为拆解草稿；历史未记录的保存时间不补造。
- DMOC 建议用电脑查看，DMS 可用手机查看。下载 index.html 后也可离线演示。
